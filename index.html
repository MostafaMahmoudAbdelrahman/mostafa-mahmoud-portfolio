Case Studies

ARCON — SiMinds & Labs for Home
Mid Unity 3D Developer · Apr 2022 – Jul 2024

Joined ARCON to build WebGL science experiments and educational simulations for UAE schools, ending up owning the architecture that let one shared codebase ship across five platforms.

SiMinds — WebGL Physics & Chemistry Experiments
  • Found each experiment shipped as a separate duplicated project/repo; proposed and led consolidating them into one project, with each experiment turned into an Addressable Prefab loaded at runtime by a launcher.
  • Owned backend connectivity and UI across all experiments.
  • Built Arduino integration to validate real hardware sensor readings against expected values.
  • Built a voice-command accessibility system for the Windows build (Windows API integration), so the experience could be operated entirely by voice for users with disabilities.
  • Built analytics APIs tracking every click/choice, plus the full scoring system.
Labs for Home — Educational Scenario App
  • Designed a step-based simulation engine: every step is PreBehaviour → Action → PostBehaviour, each an interface with many concrete implementations, with Action awaited asynchronously until it happens — a data-driven, reactive component architecture.
  • Built a PC lab simulator with full UI, a tablet report simulator used in the physical lab, and all scoring/analytics APIs.
  • Participated directly in scenario and experiment design, not just implementation.
  • Delivered 100+ educational experiments — originally for Windows, later packaged as an EXE installer, ported to Android for Chromebook deployment, and built a VR demo on Meta Quest before leaving ARCON.

Result: ARCON shipped from one shared architecture across WebGL, Windows/PC, tablet, Android/Chromebook, and VR/Meta Quest.
